Action Checklist

A simple to-do list for getting things done — add actions, set how urgent they are and when they're due, then tick them off.

How it works

  1. Name your checklist, then add an action — a short description, an urgency (low, medium, high) and a due date if it has one.
  2. Tick the box when it's done. Done items drop to the bottom and stay there, struck through, so you can see what you've cleared.
  3. Sort by due date to see what's next, or by urgency to tackle the big ones first. Anything overdue is flagged in red, due soon in amber.
  4. Save the session as a file (.json) to keep or reopen anywhere, or print it. The page also auto-saves to this browser, but that's not a real backup.
